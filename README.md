# BestCarLauncher - releases

Versiones firmadas (APK) del launcher BestCarLauncher para un radio Android de coche.

Cada release incluye:
- `BestCarLauncher-vX.Y.apk`
- `BestCarLauncher-vX.Y.apk.sha256` (SHA-256 del APK)

La app busca aqui las actualizaciones y verifica el SHA-256 antes de instalar.
